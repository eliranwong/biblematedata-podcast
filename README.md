# Bible Podcast Audio Files - Complete 66 Books

Built for [BibleMate Web](https://github.com/eliranwong/biblemateweb) (part of [BibleMate AI](https://github.com/eliranwong/biblemate)).

Created for Bible studies, not for commercial use.

## Installation

These podcast files are automatically downloaded into `~/biblemate/data/podcast` when running:

```bash
pip install -U biblematedata
biblematedata
```

For more details, see [biblematedata](https://github.com/eliranwong/biblematedata).
